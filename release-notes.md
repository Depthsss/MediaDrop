# MediaDrop 1.0.0

MediaDrop’un ilk kararlı Windows sürümü.

## Öne çıkanlar

- YouTube, Instagram, X/Twitter ve TikTok desteği
- Opera/Opera GX/Chrome/Edge companion eklentisi
- Video, MP3, hızlı klip, fotoğraf/carousel ve X gönderi kartı indirme
- İlerleme, pause/resume/cancel ve indirme sonrası doğrulama
- Eklentiden dosyayı doğrudan Explorer’da gösterme
- Arka planda çalışan güvenli Native Messaging companion

## Kurulum

`MediaDrop-Setup-1.0.0.exe` dosyasını indirin. Varsayılan olarak kapalı olan “Tarayıcı eklentisini bağla” seçeneğini açarsanız kurucu kapanmadan tarayıcı bağlantı adımına geçer; kurulu tarayıcıları algılar, varsayılanı ilk sıraya alır ve paketlenmemiş eklentiyi görünür MediaDrop penceresi açmadan bağlatır.

Bu release Windows Authenticode sertifikasıyla imzalı değildir; SmartScreen “Bilinmeyen yayıncı” uyarısı gösterebilir. Dosyayı `SHA256SUMS.txt` ile doğrulayabilirsiniz. Uygulama içi güncelleme paketi Tauri updater imzasıyla ayrıca doğrulanır.

Desteklenen sistem: Windows 10 22H2 veya Windows 11, x64.
