# Security Policy

## Supported version

Yalnız en güncel MediaDrop release’i güvenlik düzeltmeleri alır.

## Reporting a vulnerability

Bir güvenlik açığını public issue, discussion veya hata raporu olarak paylaşmayın. Aşağıdaki private vulnerability reporting formunu kullanın:

https://github.com/Depthsss/MediaDrop/security/advisories/new

Rapora mümkünse etkilenen sürümü, yeniden üretim adımlarını ve beklenen etkiyi ekleyin. Cookie, Authorization header, signed URL, kişisel dosya yolu veya gerçek hesap tokenı göndermeyin; gerekli örnekleri sentetik canary değerlerle değiştirin.

Raporun alındığı makul sürede doğrulanacak, güvenli düzeltme ve yayın zamanı rapor sahibiyle koordine edilecektir.
